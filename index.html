Presentación

El trunking es una técnica fundamental en las redes Ethernet modernas porque permite transportar información perteneciente a diferentes VLAN a través de un mismo enlace físico. Para identificar cada VLAN se utiliza normalmente el estándar IEEE 802.1Q, que agrega información de etiquetado a las tramas Ethernet.

Introducción

En una organización es común necesitar varias redes lógicas dentro de una misma infraestructura física. Las VLAN permiten separar el tráfico y mejorar la administración de la red. Sin embargo, cuando dos switches deben compartir varias VLAN, sería poco práctico utilizar un cable independiente para cada una. El trunking soluciona este problema permitiendo transportar múltiples VLAN por un único enlace.

El estándar IEEE 802.1Q define un mecanismo de etiquetado de tramas para indicar a qué VLAN pertenece cada trama que atraviesa un enlace troncal. De esta manera, los switches pueden mantener la separación lógica de las redes mientras utilizan la misma conexión física.

Importancia: el trunking permite aprovechar mejor los enlaces, facilita la expansión de redes y hace posible que una misma VLAN exista en diferentes switches.

Desarrollo

¿Qué es una VLAN?

Una VLAN (Virtual Local Area Network) es una red lógica creada dentro de una infraestructura física. Permite agrupar dispositivos independientemente de su ubicación física y separar dominios de broadcast.

¿Qué es un puerto trunk?

Un puerto trunk es un puerto configurado para transportar tráfico de varias VLAN. A diferencia de un puerto de acceso, que normalmente pertenece a una sola VLAN, el trunk utiliza etiquetas para distinguir las diferentes redes.

IEEE 802.1Q

IEEE 802.1Q es el estándar utilizado para etiquetar tramas Ethernet con información relacionada con la VLAN. La etiqueta permite que los equipos de red sepan a qué VLAN corresponde cada trama mientras atraviesa el enlace troncal.

Ventajas

  • Permite transportar varias VLAN por un solo enlace.
  • Reduce la cantidad de conexiones físicas necesarias.
  • Facilita la administración y expansión de la red.
  • Mantiene separadas las redes lógicas.
  • Permite conectar switches de forma eficiente.

Desventajas y consideraciones

  • Una mala configuración puede provocar problemas de conectividad.
  • Es necesario controlar qué VLAN pueden atravesar el trunk.
  • La configuración requiere conocimientos básicos de VLAN y switching.
  • Una falla en el enlace troncal puede afectar varias VLAN simultáneamente.

Ejemplo de configuración Cisco

Switch(config)# interface gigabitEthernet 0/1 Switch(config-if)# switchport mode trunk Switch(config-if)# switchport trunk allowed vlan 10,20,30 Switch(config-if)# no shutdown

En este ejemplo, la interfaz GigabitEthernet 0/1 se configura como trunk y se permite el transporte de las VLAN 10, 20 y 30. La configuración exacta puede variar según el modelo y sistema operativo del switch.

Aplicación en una institución

Una institución educativa podría utilizar VLAN diferentes para administración, docentes, estudiantes y visitantes. Los switches ubicados en diferentes edificios pueden conectarse mediante enlaces trunk, permitiendo que las VLAN necesarias lleguen a cada zona sin instalar un enlace físico independiente para cada red.

Conclusiones

El trunking es una solución eficiente para transportar múltiples VLAN mediante un solo enlace físico. Su funcionamiento está estrechamente relacionado con el estándar IEEE 802.1Q, encargado de identificar las VLAN mediante etiquetas en las tramas Ethernet.

Comprender la diferencia entre puertos de acceso y puertos trunk es esencial para configurar correctamente una red conmutada. Una implementación adecuada permite aprovechar mejor la infraestructura, mantener la segmentación lógica y facilitar el crecimiento de la red.

En conclusión, IEEE 802.1Q y el trunking son tecnologías fundamentales para diseñar redes organizadas, escalables y administrables.
